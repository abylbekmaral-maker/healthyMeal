# 🍽️ Healthy Meal

🌐 언어

-  [English](README_EN.md)
-  [Русский](README_RU.md)
-  한국어

Healthy Meal은 사용자의 건강 정보를 바탕으로 맞춤형 식단을 추천하고, 건강한 식습관을 관리할 수 있도록 도와주는 웹 애플리케이션입니다.

##  주요 기능

- 건강 정보 기반 맞춤 식단 추천
- 일일 식단 및 영양 정보 대시보드
- 주간 식단 플래너
- 장보기 리스트 자동 생성
- 건강 트래커 (기분 및 컨디션 기록)
- 다국어 지원 (한국어, 영어, 러시아어)
- 모바일 환경을 지원하는 반응형 UI

## 시스템 구조

- 프론트엔드 UI와 백엔드를 REST API로 연결
- Spring Boot에서 비즈니스 로직 처리
- MySQL에 사용자 및 식단 데이터 저장
- Aiven Cloud Database를 사용하여 데이터베이스 운영
- Render를 사용하여 애플리케이션 배포

## 💬 프로젝트 테스트 방법

>  처음 접속하는 경우 서버가 시작되는 데 최대 2~3분 정도 걸릴 수 있습니다. 페이지가 완전히 로드될 때까지 기다려 주세요.

1. 아래 링크를 통해 애플리케이션에 접속합니다.
2. 회원가입하거나 로그인합니다.
3. 프로필 정보를 입력합니다.
4. 식단을 생성하고 추천 내용을 확인합니다.
