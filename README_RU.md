#  Healthy Meal

🌐  Язык

-  [English](README.md)
-  Русский
-  [한국어](README_KO.md)

Healthy Meal — это веб-приложение, которое помогает пользователям придерживаться здорового питания, предлагая персональные рекомендации на основе информации об их здоровье.

##  Попробовать проект
Вы можете открыть рабочую версию приложения и самостоятельно протестировать основные функции Healthy Meal.

> ⚠️ При первом открытии приложения запуск сервера может занять 2–3 минуты. Пожалуйста, дождитесь полной загрузки.

Live Demo: https://healthymeal.onrender.com
🔗 **Подробная инструкция со скриншотами:**
[Руководство пользователя (PDF)](demo2/docs/HealthyMeal_User_Guide.pdf)

## 💬 Как протестировать

1. Откройте приложение по ссылке ниже.
2. Войдите в аккаунт или зарегистрируйтесь.
3. Заполните профиль.
4. В разделе **Planner** создайте недельный план питания.
5. После создания плана откройте страницу **Home** и просмотрите рекомендации.

##  Основные возможности

- Персональный план питания на неделю.
- Подбор блюд с учетом здоровья и целей пользователя.
- Автоматическое создание списка покупок
- Ежедневное отслеживание самочувствия
- Поддержка нескольких языков (корейский, английский, русский)
- Адаптивный интерфейс для мобильных устройств

## ⚙️  Используемые технологии

- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Backend:** Java 17, Spring Boot 3.2.0, Spring Data JPA
- **Database:** MySQL (Aiven Cloud)
- **REST API:** Spring Web
- **Validation:** Spring Validation
- **Build Tool:** Gradle
- **Deployment:** Render
- **Version Control:** Git, GitHub

##  Архитектура
Browser → Spring Boot (REST API) → Spring Data JPA → MySQL (Aiven Cloud)
Приложение развернуто на Render
