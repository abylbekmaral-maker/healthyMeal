# 🥗 Healthy Meal

🌐 Язык

- 🇺🇸 [English](README.md)
- 🇷🇺 Русский
- 🇰🇷 [한국어](README_KO.md)

Healthy Meal — это веб-приложение, которое помогает пользователям придерживаться здорового питания, предлагая персональные рекомендации на основе информации об их здоровье.

## ✨ Основные возможности

- Персональные рекомендации по питанию
- Ежедневный обзор питания и пищевой ценности
- Планировщик питания на неделю
- Автоматическое создание списка покупок
- Трекер здоровья (настроение и самочувствие)
- Поддержка нескольких языков (корейский, английский, русский)
- Адаптивный интерфейс для мобильных устройств

## 🛠️ Используемые технологии

### Frontend
- HTML5
- CSS3
- JavaScript
- Адаптивный веб-дизайн

### Backend

### База данных
- MySQL

### Развертывание
- Render

### Инструменты
- Git
- GitHub

## 🏗️ Архитектура системы

- Интерфейс взаимодействует с сервером через REST API.
- Spring Boot обрабатывает бизнес-логику приложения.
- MySQL хранит данные пользователей и информацию о блюдах.
- Aiven используется как облачная база данных.
- Render используется для размещения приложения.

## 🚀 Как протестировать

> ⚠️ При первом открытии приложения сервер может запускаться до 2–3 минут. Пожалуйста, дождитесь полной загрузки страницы.

1. Откройте приложение по ссылке ниже.
2. Зарегистрируйтесь или войдите в систему.
3. Заполните профиль.
4. Создайте план питания и изучите рекомендации.
